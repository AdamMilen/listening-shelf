# The Listening Shelf

Home vinyl catalog for GitHub Pages. Includes all ten albums recovered from the original ChatGPT conversation, mobile layouts, artist/album/song search, genre filtering, and expandable tracklists.

## Update the collection

Edit the `albums` array in `script.js`. Each entry has artist, title, original release year, genre, a local cover image path, and a track array. Optional `format` and `note` fields describe an edition. Genres and the collection count update automatically.


Tracklists use standard album sequences, without bonus tracks. The Eagles entry assumes the 19-track 2024 **2LP** edition, not the 51-track 6LP set. Exact pressing and side breaks are not verified; compare with your physical sleeves.
