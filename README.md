# The Listening Shelf
https://adammilen.github.io/listening-shelf/

Home vinyl catalog for GitHub Pages. Includes all ten albums recovered from the original ChatGPT conversation, mobile layouts, artist/album/song search, genre filtering, and expandable tracklists.

## Open locally

Open `index.html` in a browser. All assets are local; no installation, API key, build, fonts, or network requests are required.

## Update the collection

Edit the `albums` array in `script.js`. Each entry has artist, title, original release year, genre, a local cover image path, a track array, and `sideCounts` (the number of tracks per side, in A/B/C/D order). Optional `format` and `note` fields describe an edition. Genres and the collection count update automatically.
